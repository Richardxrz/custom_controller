# custom_controller_ai

> **AI 实现区**：机械臂自定义控制器的完整固件/上位机实现。
> 用户的设计在 `~/ai/50-机械臂控制器/`，用户的复刻在 `~/Embedded/stm32_module_lab/`。
> 这里的代码是**参考实现**，不是用户的框架代码。

## 角色分工（2026-10-23 定）

```
用户：需求 → 设计 → 评审 / 验收
 AI ：按设计实现 → 自测（host 优先）→ 反馈（过了什么、卡在哪、需要什么决策）
用户：功能完成后，在 stm32_module_lab 里自己复刻一遍 → 成为日后框架的一部分
```

- 本目录 = AI 的全量实现，允许直接用现成库、样板代码、快捷写法；
- `stm32_module_lab` = 用户手写复刻，风格与模块边界按用户自己的框架来；
- 两边不互相 import，靠**行为一致**（同一套 host 测试用例可以两边跑）来对齐。

## 当前结构

| 目录 | 内容 |
|---|---|
| `Module/` | `ringbuf`（字节环）、`servo_codec`（ASCII 协议）、`bus_servo`（事务/指令层）；`rx_dma` / `tx_uart_it` 来自 lab |
| `tests/host/` | 主机侧测试（不需要板子）：`run_servo.sh` |
| `App/` | 应用入口（待接入 6 轴调度） |
| `Core/` `Drivers/` `cmake/` | CubeMX 生成，来自 lab 的 C 板配置 |
